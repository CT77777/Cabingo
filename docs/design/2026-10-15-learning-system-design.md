# Cabin, Please 學習系統設計：邊玩邊準備空服考試

> 設計提案；尚未上線。醫療與緊急處置內容尚未經專業審閱。
2026-10-15

**定位**：以遊戲體驗為主，結合航空知識，讓準備**台灣航空公司**空服員招考的玩家可以邊玩邊學。

**目標招考**：中華航空、長榮航空、星宇航空為主，其他國籍航空（如台灣虎航、華信航空、立榮航空）為輔。外商航空先不納入。

**這個決定帶來的設計影響**
- **語言**：廣播與對話以華語、英文為主，加入台語廣播練習。
- **情境題**：以國籍航空常見的服務情境與用語為主，中英文都要能作答。
- **知識內容**：以台灣出發的航線、台灣旅客常見需求（例如轉機、團體旅客、長輩旅客）設計情境。
- **國籍航空通用版**：所有練習統一成國籍航空通用版，不依個別航空公司區分，也不追蹤各家流程差異。
- **語言範圍**：只做華語、英文、台語，不加入日文、韓文等其他語言。

**核心原則：先玩，後學。** 遊戲進行中不打斷節奏，最多一句提示；完整的知識說明放在章節結算、知識圖鑑和練習模式裡。玩家想學就點開，不想學也能把遊戲玩完。

## 一、空服招考會考什麼

以下整理自台灣航空公司的公開面試經驗分享，每年流程可能調整，實際內容請以各航空公司招募官網為準。英文檢定門檻、身高等報考條件依各家公告而定，遊戲內的考試資訊頁要直接連到官方公告，不自行抄寫數字。

| 考試環節 | 內容 | 遊戲可以怎麼對應 |
| --- | --- | --- |
| 英文廣播稿朗讀 | 初試常見朗讀英文廣播稿；長榮的分享提到另有一句台語廣播詞 | 廣播練習模式 |
| 中英文情境題 | 例如超賣時如何婉拒並致歉、遇到語言不通的旅客怎麼處理 | 遊戲中的判斷題轉成「面試情境題」 |
| 心算 | 長榮的分享提到心算測驗 | 免稅品販售與找零小遊戲 |
| 適職、適性測驗 | 評估服務態度、抗壓與團隊合作 | 遊戲本身的判斷與結算回饋 |
| 外語能力 | 多數航空公司要求英文能力證明 | 英文旅客對話、英文選項模式 |

## 二、學習系統的六個部分

### 1. 結算時的「為什麼」

每章結算時，列出本局做過的判斷，每一題附一段簡短解說：

> **起飛前為什麼要收起餐桌、豎直椅背？**
> 讓同排旅客在緊急情況下能快速離開座位，通道不被擋住。
> 知識點：客艙安全 · 起降前檢查

- 答錯的題目排在最前面，並標示「建議複習」。
- 解說控制在 2～3 句，附上一個知識點標籤。
- 遇到各家航空做法可能不同的地方，明確標註「各航空公司規定可能不同」。

### 2. 知識圖鑑

玩過的內容會解鎖對應的知識卡，可隨時翻閱：

| 分類 | 內容範例 |
| --- | --- |
| 機艙術語 | Galley（廚房）、Jump seat（組員座椅）、Lavatory（洗手間）、Overhead bin（頭頂置物櫃）、PA（廣播）、Interphone（機內電話） |
| 客艙安全 | 起降前檢查項目、安全帶燈、緊急出口座位條件、亂流應對原則 |
| 安全設備 | 氧氣面罩、救生衣、滅火器、急救箱、AED 的用途與位置概念 |
| 服務知識 | 特殊餐代碼（如素食、兒童餐）、過敏處理原則、酒精飲料供應原則 |
| 航空基礎 | 航空音標字母（Alpha、Bravo…）、機場代碼、24 小時制、時區換算 |
| 緊急情境 | 失壓時先戴自己的面罩、救生衣離開機艙才充氣、撤離時不攜帶行李 |

每張卡片標示「在第幾章遇到」，玩家可以回到那一章再練一次。

### 3. 廣播練習模式

對應招考的英文廣播稿朗讀。

- 主線每章開頭都有一段機長或座艙長廣播，玩過的廣播稿會解鎖到練習模式。
- 提供華語、英文、台語三種版本，附上逐字稿與示範音檔。台語版附台羅拼音，方便不熟台語的玩家練習。
- 廣播稿的格式與用語參考國籍航空的常見寫法，但不直接使用任何一家航空公司的實際稿件或名稱。
- 玩家可以錄下自己的朗讀，和示範音檔對照重播。
- 進階版（之後再做）：用語音辨識檢查發音與速度。

**廣播稿範例**：登機歡迎、安全示範、亂流提醒、餐飲服務開始、下降前準備、落地歡迎。這些內容和主線章節一一對應。

### 4. 面試情境題模式

把遊戲裡的判斷題，轉成面試會問的形式：

> **情境**：旅客在起飛後要求升等到商務艙，說他是常客。
> **請用 1 分鐘回答你會怎麼處理。**

玩家作答後（可選擇打字或錄音），顯示「答題思路」，而不是標準答案：

1. 先同理旅客的感受。
2. 說明規定與權限（例如升等通常不是空服員可以當場決定的）。
3. 提供替代方案或後續協助。
4. 維持對其他旅客的公平。

**重點**：面試沒有唯一正確答案，遊戲只提供思路框架與常見地雷，例如隨口承諾做不到的事、把責任推給公司。

### 5. 心算小遊戲：免稅品販售

放在第 4 章餐飲服務之後，作為主線的支線或獨立練習：

- 旅客用不同幣別購買免稅品，玩家要算出總額與找零。
- 難度逐步提高：單一幣別 → 兩種幣別換算 → 多件商品加折扣。
- 有時間限制，但不影響主線評分。

### 6. 錯題本與複習

- 每局答錯的判斷題、面試題、心算題自動收進錯題本。
- 下次進入遊戲時，提醒「有 3 題可以複習」，複習答對才移出。
- 學習進度頁顯示各分類的知識點完成率，例如「客艙安全 12/20」。

## 二之一、英文模式

國際航班的旅客本來就會說英文，可以自然加入：

- **部分旅客說英文**：從第 4 章開始，部分旅客的台詞與選項是英文。
- **全英文模式**：設定中可切換為全英文介面與對話，適合練習英文面試。
- **單字提示**：英文台詞中的航空用語可以點擊查看中文解釋，並收進知識圖鑑。

## 三、和遊戲體驗的平衡

| 原則 | 做法 |
| --- | --- |
| 不打斷遊戲節奏 | 遊戲中最多一句提示；完整說明只出現在結算、圖鑑和練習模式 |
| 學習是選擇 | 結算頁的「為什麼」可以展開或跳過；練習模式需要自己進入 |
| 獎勵學習 | 圖鑑完成度、廣播練習次數可以解鎖組員制服或機艙裝飾等外觀 |
| 不假裝權威 | 知識卡註明「簡化說明，各航空公司規定可能不同」，並附參考來源 |

## 四、內容正確性

學習功能會讓玩家把遊戲內容當作真的知識，所以正確性比純娛樂遊戲重要很多：

- **知識卡要有來源**：每張卡片附上參考資料，例如航空公司公開的安全說明、主管機關的公開資訊、公開的急救指引。
- **專業審閱**：所有客艙安全、緊急情境、急救相關內容，上線前請現役或退役空服員、急救講師審閱。
- **定期更新招考資訊**：招考流程每年可能調整。遊戲內的考試資訊頁要標示更新日期，並提醒以官方公告為準。
- **不涉及保安程序**：保安相關內容只做到通用原則，不呈現實際程序。

## 五、製作順序建議

1. **結算時的「為什麼」與知識圖鑑**：成本最低。現有第 2 章（起飛前巡艙）的 9 種情境就能先寫出第一批知識卡。
2. **面試情境題模式**：直接重用遊戲裡的情境，只需要多寫「答題思路」。
3. **廣播練習模式**：先做逐字稿與示範音檔，錄音對照功能其次。
4. **心算小遊戲**：跟著第 4 章一起做。
5. **英文模式與錯題本**：內容量足夠後再加入。

## 六、待決定的問題

- **示範音檔**：要請真人錄製（品質高、成本高），還是先用語音合成？
- **專業顧問**：知識卡與廣播稿由誰撰寫、誰審閱？
- **是否收費**：學習功能要不要做成付費擴充，或全部免費？
