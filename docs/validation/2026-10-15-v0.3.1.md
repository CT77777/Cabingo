# Cabingo v0.3.1 介面修正與審查

- 900px 以上的決策選項改成三欄橫排；899px 以下維持單欄。安全與服務選單皆適用，保留半透明玻璃樣式。
- 驚嘆號改為單一獨立 SVG 圖片，與文字用 flex 排版，保留 6px 間距；移除會被背景簡寫重設的背景圖示。
- 標籤先完成 DOM 更新，再集中量測實際尺寸，避免每個標籤都觸發強制版面計算。
- 寬螢幕面板統一依可用高度限制，保留頂部 HUD 空間，消除 520px 高度分界造成的突然裁切。
- 版本與快取參照同步為 0.3.1；未改動遊戲規則、評分與處理時間。

## 驗證

遊戲規則 81/81、控制器 45/45、Three.js 場景及新增事件／演出／音訊／結算測試通過；靜態版面檢查 300/300 通過。建置與差異空白檢查通過。

實際 Chrome 遊戲頁：1272px 三欄等寬，899px 單欄；390px 安全標籤僅一個圖示、文字間距 6px。932×430 安全選項均可見。另以相同正式樣式與服務面板結構的靜態版面 fixture，確認 1024×600 及 932×430 的服務選項均在視窗內；fixture 驗證後移除，不包含在交付內容。

## Claude Code 推送前審查

依使用者要求，實際透過 Claude Code 2.1.300 CLI，以唯讀方式提供差異與相關檔案內容。審查程序不允許工具操作或檔案修改；測試由實作者另行執行。

首次審查指出橫向手機高度不足，以及逐個標籤量測的效能風險。兩項均新增先失敗、再通過的回歸檢查後修正。後續也消除 521–650px 高度區間的裁切風險。最終 Claude Code 判定：No blockers. Ready to push.

非阻擋註記：舊版 Safari（15.4 以前）的 dvh 相容性尚未處理；極短畫面允許面板內捲動。保留既有遊戲的現代 WebGL 2 瀏覽器需求。
