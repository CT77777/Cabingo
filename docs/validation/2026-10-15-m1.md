# Cabingo M1：登機教學驗收

2026-10-15 · v0.6.0 · `feat/boarding-tutorial` · 基準 `origin/main` 7f3c190（已整合 M0 PR #1 與互動改善 PR #2）

## 本次可玩內容

- 第 1 章登機：指引長輩、協調滿櫃行李、核對一件座位糾紛、協助家長。四步教學不計正式時間，以實際操作推進，約30秒而不強迫等待。
- 正式段90秒，最多3個同時需求、服務耐心40秒、不可交接。紅色安全與綠色服務、實際走動與禮讓人流共用既有鍵盤空白鍵／手機搖桿／互動操作。
- 七位旅客以純規則座標從前方移動到座位；座位糾紛三種種子變體（排數、側別、日期），需比較兩張可見登機證。日期不符的旅客回前門，沒有隱藏專業航空程序。
- 旅客正常走動不算擁擠；超過3位停滯旅客（等候或走動受阻至少1秒）持續8秒記一次安全事件，同一連續擁擠只記一次。這是對原初稿「走道擁擠」的可玩性細化，避免正確處理仍必然被正常入座人流扣分。
- 所有需求完成且旅客入座／退出後，回前方金色圈正式回報。正式至少一星解鎖巡艙；可直接按下一章。
- 固定長輩外觀（金色衣服、灰髮、眼鏡）延續到巡艙的安全帶任務。僅成功正式登機寫入 helped 記憶；未曾登機的舊玩家不會被巡艙結果誤寫成「登機時幫過我」。

## 架構與存檔

- 新增 `boarding.mjs` 純規則與 `chapters/boarding.mjs` 資料。Three.js 僅讀狀態繪製；既有巡艙 API 預設章節、種子順序、計時與評分保持相容。
- `cabin3d-campaign-v2` 新玩家從登機開始。v1 過渡玩家保留巡艙入口，但不視為已通關登機；有效舊巡艙最佳星等遷移。舊 key 保留。
- 寫入前重讀並合併最高星等／角色記憶；未來版本不覆寫，讀取／寫入遭拒仍能遊玩。無後端、模型下載或語音請求。
- 首次說明儲存採聯集，避免登機說明覆蓋已看過的巡艙說明。結果焦點會落在可見的下一章或重玩按鈕。

## 人流回歸與設計限制

- 修正慢玩家座位回頭路徑與隊伍迎面卡死：入座與回前門分流、轉入座位時預留空間、等候行李處理前已保留轉身距離、後到旅客不得超車後停在前人目的地之前。
- 正常與退讓路徑共用 FIFO／座位交叉保留檢查；退讓不超出走道縱向邊界；前門生成時不與玩家重疊。
- 家長的需求標記跟著本人，即使尚在走道也可協助，不必等到目的座位。
- 玩家仍會擋住旅客，必須側身或退回前方禮讓；沒有把角色碰撞取消。這是明確保留的玩法，非承諾 NPC 能繞過任何持續站在狹窄通道的玩家。
- 正式段內的修正與等待仍會消耗行動時間；擁擠門檻與耐心是初稿，需要真人遊玩後調整。
