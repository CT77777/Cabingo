# Cabingo 0.6.2：圖像線索與登機帶領

## 範圍

接續已合併的 PR #4（main 5236bb1，內容與 49b8fd0 相同），另開功能分支 `feat/boarding-visual-tutorial`，不直接推送 main。

- 登機證改成有品牌、航班、日期、票根、條碼與大座位號的圖像票卡。座位糾紛的兩張票採相同排版，不用「今日／明日」或正誤顏色提示答案。
- 航班日期固定為劇情的 15 OCT 2026，供玩家對照票面日期。座位圖有六排、D C｜B A、機頭向下，和固定跟隨鏡頭方向一致。第一題回應使用 C／B 座，避免左右方向混淆。
- 行李以櫃內物件／空位和走道行李示意，家長情境以人物、孩子、手提袋與座位圖示呈現。保留讀螢幕軟體所需的描述；視覺介面不再重複長段答案線索。
- 第一題需要親手點開票卡和座位圖，內容會從背面揭露。可任選查看順序，數字快捷鍵也受引擎門檻保護；解鎖後焦點留在回應提示，不會自動選答案。
- 第一章引導：中央開場 → 移動 → Space／互動 → 查看與對照 → 行李 → 前往第 4 排 → 中央安全／服務／讓路／回報提醒。只有玩家確認後才開始正式 90 秒。練習有專屬不計時文案。
- 教學階段隱藏旁邊待辦和重複下方提示，一次呈現一個目標。手機標明搖桿並加框；教學過後恢復完整任務與處理提示。每次重玩可重新體驗完整引導。
- 教學期間暫緩後續五位旅客，正式開始時將出場時鐘歸零再依序入場，避免學習停留時間導致人流同時湧入。
- 正確回應發出純演出 `correct` 事件，先微笑、點頭、手勢和短暫道謝；分數和完成紀錄仍在原動作完成時才更新。登機走動／坐下模型共享反應，反應結束恢復待機；減少動態時維持笑臉，不點頭或揮手。錯誤反應過期也恢復原情緒眉型。

## 相容性

`guidedBoarding` 為選用規則參數，預設 false，保留既有純規則呼叫；正式網頁明確傳 true。沒有新增儲存鍵，沒有更改章節解鎖或長輩跨章記憶。開場與正式開始提示每局重播、不保存為已略過的提示。

## 登機場景餐車修正

依登機中不應推出餐車的回饋，登機章節隱藏玩家餐車與同事前方的供應車，包含車上的杯子與毯子。機組員保留，切換到後續巡艙恢復服務道具。

- 先加入失敗回歸測試，再修改場景；涵蓋登機 briefing／playing／paused／finished 和切換回巡艙。完整 `npm run test:all`、`npm run build` 與 `git diff --check` 通過。
- Chrome 1194×959 實際進入登機教學，確認兩處餐車皆不再顯示；沒有遊戲來源的 console error。畫面存於任務 outputs：`cabingo-boarding-no-trolley.png`。
- Claude Code 針對這次公開專案差異唯讀審查，結果 PASS。另檢查沒有後續程式覆寫道具可見性、沒有餐車拾取或碰撞邏輯，隱藏道具不會留下透明障礙。
