# 第 2 章共用處置與即時作答回饋

2026-10-16，本機實作與驗證；未推送或部署。

本記錄描述初版共用處置流程；服務提示與正確作答確認流程的後續調整見 [移除服務提示與二次確認](2026-10-16-preflight-immediate-actions.md)。

## 行為

- 僅調整第 2 章產品流程。兩模式共用巡艙題目與處置資料，三項安全檢查、飲水需求開場出現，保暖需求第 5 秒出現；無等待扣分或等待超時事件。
- 演練答錯即時解說、列出正確選擇，可重選；答對執行處置。五項任務全完成且走道淨空才可回報，只顯示完成提示與再練／選章，不產生成績或結算講評。
- 考核保留 100 秒及優先序題，共六題。每題一次；答對顯示大綠勾與所選正確做法，按繼續後執行處置；答錯顯示大紅叉與旅客頭頂的吐槽泡泡，不揭露正確選項、不執行處置。錯題仍未處置，結算才顯示正確做法與講解。
- 回饋畫面持續倒數；暫停與失焦停止。繼續按鈕支援點擊、Enter／空白鍵，按住或重複選擇不會改寫首次答案。
- 自行記錄普通需求需 3 秒、同事記錄需 1 秒，每輪一次；完成後皆為起飛後協助，不送物。考核完成六題作答並結束答對題的處置後才可提交；錯題不阻擋提交。
- 考核行李持續保留碰撞及可繞行的通路，答錯不會自動消失；演練仍需處理擋路行李。
- 評星規則沿用。共用選項後第二章所有錯誤選項皆屬安全相關，因此目前完整提交全對為 3 星，有錯或未完整提交為 0 星。第一章仍可有 1／2 星。
- 第二章考核改用題庫版本 3，保留版本 2 舊紀錄；第一章仍用版本 2。儲存拒絕與新版格式保護沿用。
