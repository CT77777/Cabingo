# Cabingo v0.5.1 互動、回饋與服務演出

獨立分支 `feat/interaction-polish`，基準 `b9166e5`（M0 PR #1 合併後）。保留另一工作目錄未提交的登機教學。本 PR 不推送或合併 main。

## 設計討論與範圍

先使用實際 Claude Code CLI 討論方案，再實作。採用 Space 開啟互動、防止按鍵穿透、中央修正卡、大字選項與投影旅客對話泡泡、類比搖桿、30／10 秒分級警示。沿用現有深藍與薄荷綠介面。

- 正式選錯維持 2 秒修正成本，之後凍結時間等候玩家讀完；練習不扣分。確認後回到相同選項順序。此新流程用在正式網頁使用的 contextual 模式；舊 handsOn API 相容測試仍保留。
- 自行送水／毯子的 contextual 處理從 1.5 秒改為 3 秒，呈現打開常駐服務車、取出物品、遞送。同事交接維持聯繫 1 秒、背景作業 12 秒，從可見的前艙補給櫃取物。服務車為視覺物件，不加入碰撞或尋路；幾何模型與關節動畫仍是風格化演出。
- 等候說明明確指出只延長該旅客耐心 12 秒、不增加巡艙時間；同事約 12 秒送達、期間可繼續巡艙。
- 依追加回饋移除強行幽默選項，以及「何時出發」需求；現在是 3 項安全檢查與 2 個服務需求。完成條件與介面同步調整。
- 每位旅客都有錯開的待機變化；等待不耐、互動疑惑、完成微笑與點頭，使用眉毛、嘴形與眼睛呈現。
- 30 秒與 10 秒各一次提示音、約 4 秒醒目橫幅；時鐘持續標色。練習不顯示倒數警示，暫停與閱讀凍結計時。
- 手機移除四方向按鈕，改為指標擷取搖桿；可斜向與小幅慢走。放手、取消、失焦、開啟面板皆歸零。鍵盤方向鍵保留。
