# 情境演練與兩章模擬考核

2026-10-16 · 分支 `codex/mock-assessment` · 本機與瀏覽器驗證，部署另行確認

## 最終行為

- 首頁只提供「開始情境演練」與「開始模擬考核」。入口跟隨目前章節；兩個已完成章節直接可選，未製作章節不可進入。
- 演練不倒數、不因服務等待超時扣分或產生超時事件；保留引導、實際處置、修正與通行碰撞，不顯示星等、不保存最佳紀錄。
- 第一章考核 90 秒、5 題（座位指引、行李、登機資訊、家長協助、優先序）；第二章 100 秒、6 題（三項安全、兩項服務、優先序）。
- 考核保留票卡／座位圖等證據及事實線索，移除教學與修正；各題直接可接觸。每題只作答一次，正誤皆不執行處置、不變更物件、不發出正誤反應，結束後才講評。
- 考核是獨立情境站點，旅客位置固定、不模擬排程。行李移到走道側邊，保留碰撞但留出通道；不要求答對才放行，也不把作答標記當作實際處置完成。
- 每章優先序題都有旅客即將跨越行李的明確風險；題內必要步驟及優先序納入判斷，獨立任務沒有唯一固定順序。
- 完整提交且無安全相關選錯：全對 3 星、錯一題 2 星、錯兩題以上 1 星；安全相關選錯或未完整提交為 0 星。安全相關選錯也包含優先序與服務選項的不安全行為，不能以其他答對抵銷。
- 最佳紀錄用新鍵 `cabingo-assessment-best-v1`，以章節與題庫版本分開。比較星等、首次錯題數、用時，只有更好才取代。零星或未完成不寫入，不存完整歷史；舊紀錄及既有收藏保留。
- 儲存前重新讀取最新資料，保留較好的紀錄及其他章節／版本。儲存拒絕仍可查看本次成績，未支援的新版格式不覆寫。沒有新增後端、帳號或外部請求。
- 結算逐題保留狀態標籤、情境與選擇做法；需要改進或尚未評量時另顯示正確做法與講解。已移除錯題重練，保留整章重考與情境演練。題庫、限時與星等皆為待專業審閱的遊戲設計，未對應公司考核標準。
