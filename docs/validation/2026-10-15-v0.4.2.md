# Cabingo v0.4.2 · 精簡桌面操作區

桌面（主要指標為滑鼠／觸控板，寬度 701px 起）移除常駐 WASD 與方向鍵介紹，操作區最多 240×48px，僅保留 E 與當前互動按鈕；外層底色、邊框與內距取消。詳細操作保留於 ⓘ。

手機 700px 以下及主要指標為觸控的裝置保持原方向鍵與互動區。觸控筆電若主要指標為滑鼠，採桌面精簡版；仍可使用鍵盤。

81 項規則、56 項控制器、場景／事件／音訊／評級測試及 306 項靜態版面檢查通過。建置與 git diff --check 通過。

實際 Chrome 1194×959 確認操作區為 240×48，只有互動按鈕；390×844 確認四個方向控制仍顯示。測試後恢復視窗尺寸。
