# Cabingo 0.6.1：走道引導與對話精簡驗證

## 修改結果

- 走道旅客：靠近按 Space 招呼，出現安全光點。玩家實際移動至少 0.4 公尺並進入光點才完成；旅客轉向、招手並演出回座。原服務需求仍待完成。
- 光點於開始時選定，取樣檢查直線路徑。碰撞位置維持不動；目標遭新障礙阻擋或離旅客超過 2.1 公尺就取消，可重新開始。暫停選單也可取消。
- 極端擁擠而沒有安全光點時，改用 2 秒回座演出，避免卡關；不顯示 loading。正式倒數到期仍優先結束，不能靠引導在逾時後拿到完成紀錄。
- 移除對話位置／分類、閱讀 footer、長篇交接提示及重複名額標籤。保留標題、現場線索、關閉與回應。桌面橫列、窄畫面直列，隨選項數量調整欄數。
- 交接名額用完或同事忙碌時不顯示交接。等候只能安排一次；文案說明優先處理走道或安全。已安排等候又被行李阻擋時，仍有不扣分的離開回應。
- 開場新增可略過的等候／交接操作示範；真實時間、耐心、名額皆不消耗。模擬同事聯繫、取水、12 秒送達；暫停與隱藏視窗會停止示範時間。
- 首次教學全部移到中央遮罩，背景不可操作，焦點受限於教學。Enter 長按不會跳過多步。
- 餐車以組員位置及朝向靠近；取物動畫使用同一個起點。Space 鍵帽自適應寬度。
- 行李上方櫃已滿但對側有可用空櫃時，「幫你放進可用空櫃」有效，模型使用對側櫃；擠入已滿櫃或留在走道才是錯誤。

## Claude Code 討論與審查

先以需求摘要討論玩法，再由同一 Codex 代理實作。Claude Code 建議採有安全終點與取消方式的移動引導，並用開場操作示範解釋耐心與背景交接。

推送前以公開專案的本次 patch 與針對性測試交由 Claude Code 審查。第一輪發現服務被阻擋時缺少免費出口、教學焦點和長按問題，均已補上。複審結果為 PASS / no blockers；另三項小建議（上方取消說明、免費出口完整分數斷言、取消後焦點）也已修正並獲確認。Claude Code 僅閱讀所提供差異，測試由 Codex 在本機執行。

已整合 main 的 PR #3 登機教學（898dffd），保留登機證線索卡、人流、長輩跨章節記憶及章節存檔。新增服務示範限起飛前巡艙；登機教學不會被額外示範阻擋。整合後包含登機完整路線的測試再次通過。

沿用 legacy hands-on 規則 API；新移動引導及開場教學僅作用於 contextual 3D 模式。未更動其他工作目錄，未直接推送或合併 main。
