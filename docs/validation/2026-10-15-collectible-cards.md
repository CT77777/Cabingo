# Cabingo v0.7.1：通關收藏卡

2026-10-15 · `feat/knowledge-codex` · 更新尚未合併的 PR #5。此版本依使用者新回饋，取代 M2 初版「開情境即解鎖」的規則。

## 收藏方式

只有正式成功通關（有有效星等紀錄，至少1星），且對應任務已完成，才獲得卡片。打開對話、走近標記、只完成部分任務後逾時、練習及零星重試均不發卡。已收藏的卡不重發；舊版儲存的卡保留，不冒稱是這版新獲得的獎勵。

同事交接完成算任務完成；登機教學任務也計入該章完成清單，但要等整章正式通關才發卡。如此長輩／行李卡仍可達成，並保留團隊合作的玩法。每局與其他分頁的收藏先合併，再計算本次新卡；未來格式不覆寫、儲存失敗保留本次記憶。

## 卡片與知識

- 8張各有原創本機 SVG 插畫、收藏編號、英文主題、簡短飛行小知識與收藏印章；桌面雙欄、手機單欄。卡背提示要完成的章節與任務。
- 結算出現本次新卡縮圖，點選後開啟指定卡片；鍵盤焦點到該卡參考資料入口，關閉後回到原獎勵按鈕。獲卡摘要有讀屏狀態與對話框說明。
- 小知識和任務解說分開，資料來源可展開查看；全數 `reviewed:false`，展開任務解說保留審閱狀態。卡片不是實際作業程序或醫療建議。
- 這些插畫由 SVG 程式碼原創繪製，無外部圖片、商標、字型或資源請求；已記錄於素材說明。所有圖片納入版本控制與靜態建置，圖片引用帶版本。

### 全新存檔的兩章實際驗收

使用不同本機來源 `localhost:4173`，不修改原 `127.0.0.1:4173` 的存檔，也不注入遊戲狀態。

1. 初始0/8；打開長輩對話並完成教學任務後仍為0/8。
2. 登機正式46秒通關（1星，擁擠事件1次、安全80、服務100），首次發4張，4/8。
3. 下一章巡艙正式35秒通關（2星、零失誤、安全100、服務94），再發4張；行李卡跨章共用，不重發，共8/8。
4. 點安全帶新卡直接定位並聚焦該卡；返回、重新載入後仍8/8。

另在原先有4張舊M2卡的測試來源完成巡艙34秒，發4張新卡；這筆保留舊資料的證據與上述全新存檔證據分開。

## Claude Code 審查與限制

推送前使用實際 Claude Code CLI 唯讀審查完整分支與這次增量。發卡門檻正確；其提出的資產未追蹤問題在提交時納入所有 SVG，建置與檔案存在測試確認。來源標籤補足濕度／氣壓、選中卡片焦點、獲卡讀屏提示、關閉按鈕可見文字與名稱、練習後再正式通關測試均補上；新焦點測試先失敗後通過。來源頁面已實際讀取，非僅依 Claude 記憶判斷。

卡片不是即時圖像翻牌：結算縮圖可打開完整卡面，只有輕微印章動畫，減少動態效果時停用。既有M1不同排座位變體的人流卡住問題不在本次修改，亦未調整任何遊戲平衡。無實機手機或GPU效能新量測，所有知識草稿仍待專業審閱。
